# Netflix Titles Analysis Dashboard

This Power BI project analyzes metadata from 8,800+ Netflix titles to uncover content trends, audience preferences, and global distribution. The dashboard is designed to support content strategy and market segmentation decisions.

---

## 📊 Features

- **KPI Cards**: Key metrics for total titles, genres, ratings, and release years  
- **Genre Distribution Pie Chart**: Visualize the spread of content across genres  
- **Decomposition Tree**: Drill down into content distribution by genre, country, and rating  
- **AI Visual - Key Influencers**: Identify the most influential factors affecting title ratings  
- **Map Integration**: Bing Maps used to visualize geographic spread of titles

---

## 🛠️ Tools Used

- **Power BI**  
- **DAX** (Data Analysis Expressions)  
- **Bing Maps**  
- **Netflix Titles Dataset** (from Kaggle or public source)

---

## 📈 Outcome

- Uncovered top-performing genres and rating trends across regions  
- Identified strategic gaps in Netflix’s content catalog  
- Delivered actionable insights for content development and regional targeting

---

## 🔗 Dataset

- Public dataset originally sourced from: [Netflix Titles on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
